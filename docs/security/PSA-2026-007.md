# PSA-2026-007 — 이미지 쓰기가 계속 실패하면 저장이 끝나지 않음

- 공개: 2026-10-25
- 심각도: 중간. 가용성. 디스크가 가득 차거나 쓰기 오류가 나면 앱이 응답 없이 CPU를 쓰며 돌았다.
- 영향을 받는 판: 4c4c73c(2026-09-28)부터 8cc964f 앞까지(코드를 읽어 정한 범위)
- 고친 커밋: 8cc964f

## 무엇이었나

저장 뒤 리스트의 검사점을 쓰는 고리가 쓰기의 실패를 보지 않아, 실패한 같은 리스트를 바로 다시 골랐다. 쓰기가 계속 실패하면 저장이
끝나지 않았다(pure-run, 그리고 serve에서 앱이 시작할 때의 저장).

## 고침

검사점 쓰기가 실패하면 그 저장에서는 멈추고, 다음 저장에서 다시 해 본다.

## 회귀 시험

`core/test-module.c`의 `failing_checkpoints`: 검사점의 이미지 쓰기를 늘 실패하게 한 채 저장을 거듭해도 저장이 돌아오는지, 쓰기가 되살아나면
다음 저장에서 써지고 재시작 뒤 리스트가 그대로인지 본다. 고치기 전에는 끝나지 않는다.
