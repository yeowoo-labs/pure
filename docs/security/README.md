# 보안 공지

Pure의 보안 결함을 고친 뒤의 요약이다. 공지마다 고친 커밋, 영향을 받는 판, 회귀 시험을 적는다. 결함을 잠그는 시험은 이 저장소의
`tests/`와 `core/test-*.c`에 있다. 공지 번호는 Pure·aup·Vega가 함께 쓰고, aup와 Vega의 공지는 각 저장소의 `docs/security/`에 있다
(PSA-2026-010은 aup, 011은 Vega). 커밋은 2026-10-28에 다시 쓴 이력의 것이다.
